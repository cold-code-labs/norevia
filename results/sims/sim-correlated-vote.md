## Hypothesis (preregistered before the run)
Registered in `results/sims/PREREGISTRATION.jsonl` (2026-11-07T22:30:55Z, v1.0.0, code sha256 `db92960b8b0fdce8…`). Amendment v1.1.0 (22:31:30Z), after the 1st run: ρ = 0.025/0.05/0.075 added to refine the boundary — hypothesis and criteria unchanged; the verdicts were the same in both versions. Amendment v1.2.0 (22:41:36Z): sensitivity analysis requested by coordination (below); it does not change P1–P4 or their numbers (same seeds).

Correlated errors impose a ceiling on majority-vote accuracy; above a critical correlation, 1 high-effort agent beats any N of low-effort agents in accuracy, and the cost of reaching an accuracy target favours the single agent when returns to effort are not strongly diminishing.

- **P1** — With p_L=0.6 and p_H=0.8 (k=4, β=0.5), the theoretical vote ceiling is Φ(z_L/√ρ); the predicted critical correlation is ρ_c=(z_L/z_H)² ≈ 0.091. For every ρ ≥ 0.1 the single agent has higher accuracy than the vote for **every** N in 1..64 (paired 95% CI excludes 0).
- **P2** — With ρ=0 there is an N ≤ 25 at which the vote beats p_H=0.8 (paired 95% CI excludes 0).
- **P3** — At equal budget (N=k low-effort agents vs 1 agent with effort k), the region where the vote wins shrinks as ρ grows and as β grows; with β=1 the single agent wins for every k ≥ 3 and every ρ.
- **P4** — Minimum cost to reach targets 0.7/0.8/0.9: with β ≥ 0.5 the single agent is cheaper for every ρ; with β=0.25 the vote is cheaper only for targets ≥ 0.9 and ρ ≤ 0.1.

## Model
- Binary task with a single correct answer. Task latent factor S ~ N(0,1) shared by all agents; agent i is correct if √ρ·S + √(1−ρ)·ε_i < Φ⁻¹(p). Marginal = p; ρ is a **latent** correlation (the JSON also reports the observable φ correlation between errors).
- Effort e → p(e) = 1 − 0.4·e^(−β) (p(1)=0.6; with β=0.5, p(4)=0.8). β ∈ {0.25; 0.5; 1} = return to effort.
- Cost = sum of efforts (low-effort agent = 1, high-effort agent = k). No aggregation/communication cost (favours the vote).
- Majority vote; ties broken by a coin flip. Binary answer = worst case for the vote (all errors coincide).
- 20,000 tasks per ρ, common random numbers across N, k and β (paired comparisons). Cross-validation against exact numerical integration over S.

## Sensitivity analysis (v1.2.0, exploratory — requested by coordination)
Calibration taken from the literature (author-reported, not validated here): agreement of ~0.6 between two LLMs that are both wrong, vs 1/3 by chance (`lit-correlated-errors`); a single-agent accuracy threshold of ~45% above which multi-agent coordination stops paying off (`lit-scaling-agent-systems`, Kim et al., arXiv:2512.08296v3). Expectation stated before running: see `SENSITIVITY.expectation` in the code.

Design: p ∈ {0.2…0.9}, ρ ∈ {0; 0.2; 0.4; 0.55; 0.7}, K=2 (binary) or K=4 (when wrong, picks the attractor answer with prob. 0.63 → agreement among wrong agents ≈ 0.6), N ∈ {3,5,9}, 20,000 tasks per cell. "Same p" = vote of N vs 1 identical agent; "equal budget" = vote of N vs 1 agent with effort N (β=0.5). Criterion: gain with paired 95% CI > 0.

Reading:
- **Same p:** the vote only helps **above** a p threshold (0.55 in the binary case; 0.30–0.40 with K=4 and attracted errors). The vote's gain grows up to p≈0.6–0.8 and falls near p→1 (ceiling effect). This is consistent with diminishing returns at high p, but the mechanism in the model is only the ceiling.
- **Equal budget:** the model predicts the **opposite** of the threshold reported by Kim et al.: the vote only beats 1 agent of equivalent effort at **high** p (≥ 0.7) and low ρ, and never wins with ρ ≥ 0.55 — the regime the literature indicates as realistic. Below ~0.45 the single agent always wins here, by a wide margin.
- **Divergence from the literature:** the Kim et al. threshold comes from agentic systems with coordination overhead, error amplification and sequential tasks — mechanisms absent from this voting model. The comparison neither validates nor refutes that report; it indicates that the ~45% effect **does not arise from aggregation with correlated errors alone** and should be sought in coordination cost / error propagation (a candidate test for the Observatory). The result also depends on the assumed effort curve.
- Data: `results.sensitivity.cells[]` (gains, CIs, thresholds) to mark the reference line p=0.45 on the phase diagram.

## Interpretation
- The central result is analytical (ceiling Φ(z_L/√ρ)) and the simulation confirms it: the MC matches the numerical integration (98.4% coverage of the 95% CIs).
- **Small** error correlations already change the decision: φ ≈ 0.03 between errors (latent ρ 0.05) moves the crossover point from N=19 to N=49. Measuring the error correlation between samples of an LLM is therefore a prerequisite for any "more agents" policy.
- The equal-budget verdict depends strongly on the return-to-effort curve p(e). With β ≥ 0.5 the single agent dominates; only with strongly diminishing returns (β=0.25) and nearly independent errors does the vote pay off.

## Limitations
- Binary answer (worst case for the vote). With a large answer space and dispersed errors, plurality is stronger — not modelled.
- The p(e) curve is an assumption, not a measurement. The high-effort agent shares the same task latent factor (same ρ).
- No aggregation, communication or latency cost; no heterogeneity between agents (model diversity).
- **What needs validation with real LLMs:** (i) error correlation between samples/agents by task type; (ii) accuracy × reasoning-effort curve (effective β); (iii) whether the observed vote ceiling matches the estimated Φ(z_L/√ρ).
