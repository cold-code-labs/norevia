# External isolation of a compromised component

**Status: open.** Proposed engineering hypothesis. No defensive experiment has run.

## Variable
trigger for dropping an agent as an evidence source: none / behavioural trust score from verified outputs / credential revocation on an external alarm

## Outcomes
time to isolation, collateral isolation of healthy agents, residual influence of the compromised agent

## Prediction
an externally enforced trust score isolates earlier than manual review with low collateral

## Refutation criterion
cheating agents evade the score (adaptive adversary in an isolated sandbox), or revocation on the same alarm is as fast

## Strong conventional baseline
EDR-style quarantine; credential rotation; user and entity behaviour analytics

## Evaluation scope and limits
Synthetic or licensed cases in owned or isolated environments. Match cost and legitimate-task utility; report false positives, missed incidents and verifier error. No third-party targets. Detailed cases, stopping rules and an execution budget must be pre-registered before a run. This research proposal grants no operational permissions.
