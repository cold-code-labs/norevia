# False-positive and alert-fatigue control

**Status: open.** Proposed engineering hypothesis. No defensive experiment has run.

## Variable
corroboration rule: single source / k agent votes / k independent evidence types (tool outputs, probes, ground-truth checks) / SIEM-style rule

## Outcomes
false containment rate, missed-incident rate, open-alert queue size, analyst-equivalent minutes; links H-01, H-08, H-13

## Prediction
counting agent votes keeps false containment high (consistent with wrong answers agreeing, 0.4-0.55, and false success 0.5-0.6); counting independent evidence types lowers it

## Refutation criterion
independent-type corroboration is no better than agent votes, or its missed-incident rate rises more than the false positives it removes

## Strong conventional baseline
SIEM correlation rules, deduplication and severity scoring, threshold alerting

## Evaluation scope and limits
Synthetic or licensed cases in owned or isolated environments. Match cost and legitimate-task utility; report false positives, missed incidents and verifier error. No third-party targets. Detailed cases, stopping rules and an execution budget must be pre-registered before a run. This research proposal grants no operational permissions.
