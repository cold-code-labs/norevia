# Alarm vs inhibitory signals

**Status: open.** Proposed engineering hypothesis. No defensive experiment has run.

## Variable
signal type: none / global pause / targeted inhibitory signal naming the risky tool or source / alarm recruitment only

## Outcomes
harmful actions prevented, unrelated work preserved, signal-induced downtime

## Prediction
targeted inhibition (with threat information) prevents as many harmful actions as global pause with much less lost work

## Refutation criterion
a static per-tool deny rule fed the same information matches; or targeted signals miss more than 2 points

## Strong conventional baseline
circuit breaker, kill switch, per-tool deny list, rate limiting

## Evaluation scope and limits
Synthetic or licensed cases in owned or isolated environments. Match cost and legitimate-task utility; report false positives, missed incidents and verifier error. No third-party targets. Detailed cases, stopping rules and an execution budget must be pre-registered before a run. This research proposal grants no operational permissions.
