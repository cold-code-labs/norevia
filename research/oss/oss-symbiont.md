## Mechanism

1. **Communication topology.** Pub/sub with named channels in the `Mycelium`: `publish` records the channel statistic and does a parallel fan-out to all subscribers (`symbiont/core/mycelium.py:L75-L109`) **[code]**. Each agent subscribes to `caste:<name>` and `broadcast` (`symbiont/agents/base.py:L122-L134`) **[code]**. The channel `weight` ("adaptive bandwidth") **does not alter delivery**: `publish` does not read it (`mycelium.py:L92-L106`); it only enters the `flow_score` computation and pruning **[code]**. In parallel there is the `MurmurationBus` with at most 7 neighbors per agent (`symbiont/config.py:L70`; `symbiont/core/murmuration.py:L78-L88`, `L97-L114`) **[code]**. The task pipeline, however, is a sequence of direct method calls (`symbiont/organism.py:L354-L527`), not messages through the Mycelium **[code]**.
2. **Who decides who acts.** (a) Phase: `Governor.transition_to` fixes the "leader" caste per phase (`symbiont/core/governance.py:L70-L76`, `L95-L110`) **[code]**. (b) Decision: `WaggleProtocol` dispatches scouts and declares as winner the option with `>= quorum_threshold` **distinct** scouts (`symbiont/core/waggle.py:L52-L61`), with thresholds by task keyword (`organism.py:L623-L637`; `symbiont/types.py:L60-L65`: LOW=2, MEDIUM=4, HIGH=6, CRITICAL=8) **[code]**. Without quorum, the first active Major casts the tie-breaking vote via LLM (`organism.py:L414-L427`) **[code]**. (c) Execution: worker chosen by round-robin (`organism.py:L447-L449`) **[code]**. (d) Birth: the Queen consumes demand signals (`symbiont/agents/queen.py:L71-L79`; `symbiont/core/castes.py:L62-L83`) **[code]**. Inference from static reading (not executed): `_dispatch_scout` only considers `ACTIVE` scouts (`organism.py:L535-L538`) and the initial population has 2 scouts (`organism.py:L209-L214`); since `check_quorum` requires distinct scouts, MEDIUM/HIGH/CRITICAL quorum appears unreachable without new scouts, falling back to the Major's tie-break. Moreover, the vote compares the `option` string extracted from the LLM's free text (`symbiont/agents/scout.py:L97-L106`), so convergence requires literal equality.
3. **Termination criterion.** `execute` is a single pass through 5 phases, with no repetition loop (`organism.py:L389-L527`) **[code]**. Limits with defaults: `recruitment_rounds=2`, `scout_timeout_sec=60.0`, `max_scouts=7` (`config.py:L76-L83`; used in `waggle.py:L117`, `L140-L144`, `L173-L184`) **[code]**. The `TopologyEngine` runs in a perpetual loop every `probe_interval_sec=30.0` (`symbiont/core/topology.py:L77-L86`; `config.py:L64`), explicitly "Never done" (`topology.py:L11`) **[code]**. In the `ResearchSquad`: `MAX_TODOS = 10` and abort if the same artifact fingerprint appears 3× (`symbiont/research_squad.py:L111-L112`, `L249-L263`) **[code]**.
4. **Verification/mechanical acceptance.** There is no deterministic acceptance in the main loop. "VALIDATION" calls `_review_artifact`, which asks the LLM for a review and marks `APPROVED` if the substring `"approve"` appears in the response (`symbiont/agents/worker.py:L113-L122`) — LLM-judge with fragile parsing **[code]**. The review result does **not** decide success: `tolerance.record_success` and `successes.record` fire when an `artifact_id` exists (`organism.py:L508-L517`) **[code]**. The worker artifact's quality is constant (`quality=0.7`, `worker.py:L73`) and the scout's is a length/keyword heuristic (`scout.py:L108-L119`) **[code]**. In the `ResearchSquad`, ```bash``` blocks are executed in the sandbox, but the exit code is only appended to the text (`research_squad.py:L404-L427`); the sub-task counts as completed if there is any output (`return new_artifacts, bool(code or research)`, `research_squad.py:L270`) **[code]**.
5. **Cost control/technical budget.** No token/cost/call limit that interrupts execution — not found (search: `budget`, `cost`, `max_tokens`, `token`, `max_iter`, `max_round`). There is: a per-caste population ceiling (`config.py:L19-L55`; `castes.py:L43-L46`); `max_tokens=2048` per call in the `AnthropicBackend` (`symbiont/backends.py:L259`); `cost_weight` only appears in the summary (`castes.py:L119-L120`) **[code]**. `oxe_bridge.py` sums fixed estimated costs per stage (`symbiont/oxe_bridge.py:L68-L74`, `L424-L611`) — tracking, not a limit **[code]**. The claim "~$0.001 vs ~$0.05, 50x" is **[README/docs]** (`docs/VALIDATION.md:L74-L76`), without measurement.
6. **Memory.** Bounded in parts: Mycelium log with 10,000 items, truncated to half (`mycelium.py:L67`, `L207-L210`); Murmuration signal log with 5,000 (`murmuration.py:L59`); scratchpad with a TTL of 1800 s and pruning by score < 0.3 (`symbiont/scratch.py:L31-L32`, `L163-L183`) **[code]**. Without limit: the `Mound` (artifact dicts, `symbiont/core/mound.py:L37-L42`, `L54-L65`), `WaggleProtocol._sessions` (`waggle.py:L78`, `L106`) and the IMI buffer (`symbiont/memory.py:L92-L100`) **[code]**. The IMI depends on an external package in `~/experimentos/tools/imi`, absent from the repo; without it, it runs "without memory" (`memory.py:L28-L29`, `L45-L57`) **[code]**.
7. **Failures/retry.** Per-agent circuit breaker on `think` and `publish`: it opens after 3 consecutive failures and has a 60 s cooldown (`symbiont/core/circuit_breaker.py:L23-L24`, `L61-L110`; `base.py:L80-L82`) **[code]**. With the breaker open, `think` **returns a fallback string as if it were a response** (`base.py:L327-L329`), which continues through the pipeline and can become an artifact counted as success (inference from `worker.py:L64-L88` + `organism.py:L508-L517`) **[code]**. The organism's `CircuitBreakerRegistry` only appears in `status()` (`organism.py:L104`, `L668-L671`) **[code]**. A high error rate causes a request for **more** Majors (opus) (`organism.py:L596-L601`) **[code]**. `ResearchSquad`: 3 attempts with 1/2/4 s backoff (`research_squad.py:L361-L380`) **[code]**. `elect_queen` exists (`governance.py:L201-L243`), but is only called in a test (`tests/test_organism.py:L300`) **[test]**.
8. **Communication pruning.** Yes, by idleness. `run_cycle`: a channel with no new messages for `prune_idle_cycles=10` cycles is attenuated ×0.5 each cycle (`topology.py:L134-L138`; `config.py:L63`); the Mycelium removes the channel and the subscriptions when `weight < 0.1` (`mycelium.py:L189-L201`) **[code]**. Reinforcement is **by volume**: `flow_score += (msg_count - usage_count) * weight` (`topology.py:L117-L121`), and it reinforces ×(1.1 + fraction) if the fraction of the total flow is `>= reinforce_threshold/10` = 0.07 (`topology.py:L125-L132`; `config.py:L62`) **[code]**. Since `weight` multiplies the next increment, there is positive feedback by volume. No correctness variable enters the computation, although the docstring speaks of "paths that produced good results" (`topology.py:L9`) and the comment says "Accumulated quality" (`topology.py:L30`) **[code]**.
9. **Elastic vs fixed.** Elastic only for growth: Scout/Media/Major are born by demand signal (`organism.py:L397-L400`, `L437-L440`, `L596-L601`; `queen.py:L71-L79`), with a `max_instances` ceiling **[code]**. There is no shrinking: `hibernate()`, `register_death` and `warm_pool_size` are not called outside tests or configuration (search: `.hibernate()`, `register_death`, `warm_pool_size`) **[code]**. Possible double counting (static reading): `queen._spawn_one` calls `register_birth` (`queen.py:L97-L101`) after `organism._spawn_agent`, which already called it (`organism.py:L335-L336`).
10. **Cost vs quality benchmark.** Absent. `benchmarks/bench_research_squad.py` measures latency with a mock LLM (`MOCK_LLM_DELAY = 0.01`, `L30-L35`) **[example]**. `docs/VALIDATION.md` reports "91/91 unit tests pass" (`L29-L31`) and timings with EchoBackend (`L138-L145`) **[README/docs]**, and acknowledges "EchoBackend tests only" (`L236`). The topology tests only check the cycle counter and the health format (`tests/test_organism.py:L97-L115`) **[test]**.

- **Gaps:** there is no measurement of task quality or of real cost; there is no test of the path with the Queen wired to the TopologyEngine.
- No code was executed; no benchmark reproduced.

**Comparison with the previous study (A4 Master, rev. 2):**
- **Confirmed:** the README brings together mycelium, Physarum, ants, bees, termites, starlings, contextual leadership (wolf/mole-rat) and temporary coalitions (dolphin) (`README.md:L21-L28`). Castes are mapped to model tiers. Governance, topology, quorum, circuit breaker and memory modules exist. Apache-2.0 confirmed in the `LICENSE` file. `run_cycle` updates `flow_score` by the increase in `message_count` × channel weight, reinforces high relative flow and attenuates idle paths. The exploration block only creates `probe:*` records when there is a `_queen` and does not call spawn (`topology.py:L145-L151`). The concern "activity reinforced without proof of a correct result" holds.
- **Added/corrected:** (i) in the organism, `topology.wire(self.mycelium)` is called **without** a queen (`organism.py:L189`), so the exploration block is inactive by default. (ii) If activated, the `probe:*` records do not exist in the Mycelium and never have `idle_cycles` incremented (the step-2 loop only iterates over real channels, `topology.py:L113`), so they are never pruned. Since `probe_count = max(1, int(len(self._paths) * 0.15))` includes the probes themselves (`topology.py:L146`), the `_paths` set would grow without limit (static inference). (iii) The lack of a link to the result goes beyond the topology: the "success" recorded in memory and tolerance depends only on the existence of an artifact (`organism.py:L508-L517`), and trust in the `Governor` rises by +0.05 on every `clear_current_task`, including on reviews (`governance.py:L150-L155`; `base.py:L402-L406`).

## Engineering analogue

*(engineering hypothesis)* For the Swarm Efficiency Observatory, SYMBIONT is a case of **reinforcement without an oracle**: the signal that thickens channels and accumulates "successes" is volume or the existence of output. Direct mapping: replace `flow_score += Δmessages × weight` with `Δverifier_accepted_tasks × weight` and compare cost per accepted task among (a) 1 strong agent (opus tier), (b) the caste pipeline with volume reinforcement and (c) the same pipeline with acceptance reinforcement. The scout quorum with literal string equality serves as a negative control for "cheap consensus".

## Testable hypothesis

1. *(hypothesis)* On tasks with an executable test, reinforcing channels by message volume (as in `topology.py:L119`) does not improve the rate of accepted tasks relative to uniform weights and increases tokens per accepted task by ≥ 10%. Metric: tokens (or US$) per task accepted by tests; falsifiable if volume reinforcement reduces this cost.
2. *(hypothesis)* With the default initial population (2 scouts), the fraction of Waggle sessions decided by quorum (`session.decided`) for tasks classified MEDIUM+ is ~0, and the decision falls to the Major. Metric: proportion of `decided` vs tie-break per quorum class; falsifiable if there are MEDIUM+ quorum decisions without additional scout spawning.
